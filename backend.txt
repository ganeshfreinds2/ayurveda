To develop the back-end for your mobile app focused on Ayurveda and home remedies based on Rajiv Dixit’s teachings, we’ll create a **Node.js** application using **Express** and **Sequelize** as the ORM for interacting with the PostgreSQL database. The back-end will support the data model defined earlier, which includes tables for `Users`, `User_Problems`, `Remedies`, `Videos`, `Articles`, `User_Saved_Remedies`, `User_Interactions`, `Recommendations`, and `Metadata`, with partitioning for `User_Interactions` and `Recommendations` and `pgvector` for vector-based recommendations. The back-end will provide REST API endpoints for the app’s core features (user management, problem submission, remedy retrieval, video/article access, and personalized recommendations) and integrate with a recommendation system leveraging vector similarity and content-based filtering.

### Tech Stack
- **Runtime**: Node.js (v18 or later).
- **Framework**: Express (for REST API).
- **ORM**: Sequelize (for PostgreSQL interaction).
- **Database**: PostgreSQL with `pgvector` extension.
- **Additional**:
  - **Redis**: For caching recommendations.
  - **SentenceTransformers**: For generating vector embeddings (via Python script or API).
  - **node-cron**: For scheduling recommendation updates.
  - **bcrypt**: For password hashing.
  - **jsonwebtoken**: For authentication (JWT).
  - **cors**: For cross-origin requests.
- **Environment**: dotenv (for configuration).

### Back-End Requirements
1. **API Endpoints**:
   - User management (register, login).
   - Problem submission and retrieval (`User_Problems`).
   - Remedy, video, and article retrieval (`Remedies`, `Videos`, `Articles`).
   - Save remedies (`User_Saved_Remedies`).
   - Track interactions (`User_Interactions`).
   - Fetch personalized recommendations (`Recommendations`).
   - Fetch metadata (disclaimer).
2. **Recommendation System**:
   - Combine vector similarity (`pgvector`) with content-based filtering (tags, categories).
   - Cache recommendations in Redis.
   - Schedule daily updates with `node-cron`.
3. **Security**:
   - Hash passwords with bcrypt.
   - Use JWT for authentication.
   - Sanitize inputs to prevent SQL injection.
4. **Scalability**:
   - Handle partitioned tables (`User_Interactions`, `Recommendations`).
   - Optimize queries with indexes.
   - Cache frequently accessed data.

```
const jwt = require('jsonwebtoken');

const auth = (req, res, next) => {
    const token = req.header('Authorization')?.replace('Bearer ', '');
    if (!token) return res.status(401).json({ error: 'No token provided' });

    try {
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        req.user = decoded;
        next();
    } catch (err) {
        res.status(401).json({ error: 'Invalid token' });
    }
};

    try {
        const user = await User.findOne({ where: { email } });

        const isMatch = await bcrypt.compare(password, user.password_hash);

        const token = jwt.sign({ user_id: user.user_id }, process.env.JWT_SECRET, { expiresIn: '1h' });
        res.json({ token });
    } catch (err) {
        res.status(500).json({ error: err.message });

const express = require('express');

// Get recommendations
router.get('/:user_id', auth, async (req, res) => {
    const { user_id } = req.params;
    try {
        // Check Redis cache
        const cacheKey = `recommendations:user:${user_id}`;
        const cached = await redisClient.get(cacheKey);
        if (cached) return res.json(JSON.parse(cached));

        // Fetch from database
        const recommendations = await sequelize.query(`
            SELECT r.remedy_id, r.title, r.description, rec.score
            FROM Recommendations rec
            JOIN Remedies r ON rec.remedy_id = r.remedy_id
            WHERE rec.user_id = :user_id
            ORDER BY rec.score DESC
            LIMIT 10
        `, {
            replacements: { user_id },
            type: sequelize.QueryTypes.SELECT,
        });

        // Cache results
        await redisClient.setEx(cacheKey, 3600, JSON.stringify(recommendations));
        res.json(recommendations);
    } catch (err) {
        res.status(500).json({ error: err.message });
    }
});

// Get real-time recommendations for a problem
router.get('/problem/:problem_id', auth, async (req, res) => {
    const { problem_id } = req.params;
    try {
        const problem = await UserProblem.findByPk(problem_id);
        if (!problem) return res.status(404).json({ error: 'Problem not found' });

        const recommendations = await sequelize.query(`
            SELECT r.remedy_id, r.title, r.description,
                   (r.embedding <=> :problem_embedding) AS distance
            FROM Remedies r
            WHERE r.related_problems @> :problem_name::jsonb
            ORDER BY distance ASC
            LIMIT 10
        `, {
            replacements: {
                problem_name: `["${problem.problem_name}"]`,
                problem_embedding: problem.embedding || '[0]'::VECTOR,
            },
            type: sequelize.QueryTypes.SELECT,
        });

        res.json(recommendations);
    } catch (err) {
        res.status(500).json({ error: err.message });
    }

// services/embeddingService.js
const { PythonShell } = require('python-shell');

const generateEmbedding = async (text) => {
    if (!text) return null;
    return new Promise((resolve, reject) => {
        PythonShell.runString(`
            from sentence_transformers import SentenceTransformer
            model = SentenceTransformer('all-MiniLM-L6-v2')
            embedding = model.encode('${text}').tolist()
            print(embedding)
        `, null, (err, results) => {
            if (err) return reject(err);
            resolve(JSON.parse(results[0]));
        });
    });
};

module.exports = { generateEmbedding };

// jobs/recommendationJob.js
const cron = require('node-cron');
const sequelize = require('../config/db');
const User = require('../models/User');
const UserProblem = require('../models/UserProblem');
const Remedy = require('../models/Remedy');
const Recommendation = require('../models/Recommendation');
const redisClient = require('../config/redis');

const start = () => {
    // Run daily at midnight
    cron.schedule('0 0 * * *', async () => {
        console.log('Running recommendation job...');
        try {
            const users = await User.findAll();
            for (const user of users) {
                const problems = await UserProblem.findAll({ where: { user_id: user.user_id } });
                const remedies = await Remedy.findAll();

                const recommendations = [];
                for (const problem of problems) {
                    for (const remedy of remedies) {
                        let score = 0;

                        // Vector similarity (50%)
                        if (problem.embedding && remedy.embedding) {
                            const distance = await sequelize.query(
                                'SELECT (:problem_embedding <=> :remedy_embedding) AS distance',
                                {
                                    replacements: {
                                        problem_embedding: problem.embedding,
                                        remedy_embedding: remedy.embedding,
                                    },
                                    type: sequelize.QueryTypes.SELECT,
                                }
                            );
                            score += 0.5 * (1 - distance[0].distance);
                        }

                        // Content-based (30%)
                        if (remedy.related_problems?.includes(problem.problem_name)) {
                            score += 0.3;
                        }

                        // Preferences (20%)
                        if (user.preferences?.preferred_categories?.includes(remedy.category)) {
                            score += 0.2;
                        }

                        if (score > 0) {
                            recommendations.push({
                                user_id: user.user_id,
                                remedy_id: remedy.remedy_id,
                                score,
                            });
                        }
                    }
                }

                // Insert recommendations
                await Recommendation.destroy({ where: { user_id: user.user_id } });
                await Recommendation.bulkCreate(recommendations);

                // Cache recommendations
                const cacheKey = `recommendations:user:${user.user_id}`;
                const cachedRecommendations = await sequelize.query(`
                    SELECT r.remedy_id, r.title, r.description, rec.score
                    FROM Recommendations rec
                    JOIN Remedies r ON rec.remedy_id = r.remedy_id
                    WHERE rec.user_id = :user_id
                    ORDER BY rec.score DESC
                    LIMIT 10
                `, {
                    replacements: { user_id: user.user_id },
                    type: sequelize.QueryTypes.SELECT,
                });
                await redisClient.setEx(cacheKey, 3600 * 24, JSON.stringify(cachedRecommendations));
            }
            console.log('Recommendation job completed.');
        } catch (err) {
            console.error('Recommendation job error:', err);
        }
    });
};

module.exports = { start };
```

### Setup Instructions
1. **Initialize Project**:
   - Create a new directory (`backend`) and run:
     ```bash
     npm init -y
     ```
   - Install dependencies:
     ```bash
     npm install bcryptjs cors dotenv express ioredis jsonwebtoken node-cron pg python-shell sequelize
     npm install --save-dev nodemon
     ```

2. **Configure Environment**:
   - Create a `.env` file in the `backend` directory with the contents from the artifact.
   - Update `DATABASE_URL` with your PostgreSQL connection string (e.g., `postgres://user:password@localhost:5432/ayurveda_app`).
   - Update `REDIS_URL` if using a hosted Redis instance (e.g., Redis Labs).
   - Set a secure `JWT_SECRET`.

3. **Set Up PostgreSQL**:
   - Ensure the database is created and the SQL script from the previous response is executed.
   - Verify the `pgvector` extension is enabled:
     ```sql
     CREATE EXTENSION vector;
     ```

4. **Set Up Redis**:
   - Install Redis locally or use a cloud provider (e.g., Redis Labs).
   - For local setup (Ubuntu):
     ```bash
     sudo apt-get install redis-server
     redis-server
     ```
   - Test connection:
     ```bash
     redis-cli ping
     ```

5. **Embedding Generation**:
   - Install Python and SentenceTransformers:
     ```bash
     pip install sentence-transformers
     ```
   - The `embeddingService.js` uses `python-shell` to call SentenceTransformers. Ensure Python is accessible in your environment.
   - Alternatively, set up a separate Python microservice for embeddings:
     ```python
     from flask import Flask, request, jsonify
     from sentence_transformers import SentenceTransformer

     app = Flask(__name__)
     model = SentenceTransformer('all-MiniLM-L6-v2')

     @app.route('/embed', methods=['POST'])
     def embed():
     ```

### Recommendation System
- **Daily Updates**:
  - The `recommendationJob.js` runs daily at midnight, computing scores based on:
    - **Vector Similarity (50%)**: Cosine distance between `User_Problems.embedding` and `Remedies.embedding`.
    - **Content-Based (30%)**: Match `problem_name` to `related_problems`.
    - **Preferences (20%)**: Match user’s `preferences.preferred_categories` to `category`.
  - Results are stored in `Recommendations` and cached in Redis.
- **Real-Time Recommendations**:
  - The `/api/recommendations/problem/:problem_id` endpoint computes recommendations on-the-fly using vector similarity and content-based filtering.
- **Caching**:
  - Recommendations are cached in Redis for 24 hours (`recommendations:user:${user_id}`).
  - Cache is refreshed daily or when new problems are submitted.

### Security Notes
- **Password Hashing**: Uses bcrypt with 10 salt rounds.
- **Authentication**: JWT tokens expire in 1 hour. Refresh tokens can be added for longer sessions.
- **Input Sanitization**: Sequelize escapes SQL inputs, but validate user inputs (e.g., `problem_name`, `description`) to prevent injection.
- **CORS**: Configured to allow requests from your React Native app’s origin (update in production).

### Scalability Notes
- **Partitioning**: The back-end handles partitioned tables (`User_Interactions`, `Recommendations`) transparently via Sequelize.
- **Redis Caching**: Reduces database load for recommendations.
- **Database Optimization**: Indexes (GIN, hnsw) ensure fast queries for searches and vector similarity.
- **Horizontal Scaling**: Deploy multiple Node.js instances with a load balancer (e.g., Nginx) and use `pgBouncer` for PostgreSQL connection pooling.
